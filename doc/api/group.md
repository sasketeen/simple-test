# Учебная группа
___

| Поле          | Описание             | Пример значения | Валидация                        |
|---------------|----------------------|-----------------|----------------------------------|
| name          | Название группы      | "Группа 2015-1" | Минимум 1 символ                 |
| student_count | Количество учащихся  | 25              | Число >= 0                       |

[//]: # (| teachers   | ID преподавателей    | ["1", "12"]          |                                                                  |)


## Методы

**CREATE**\
Доступность: только администраторам\
Описание: Создание новой группы. Поля `name` и `student_count` обязательны

**UPDATE**\
Доступность: только администраторам
Описание: Обновление данных группы.

**READ**
Доступность: всем\
Описание: Просмотр информации о группе.

**DELETE**\
Доступность: только администраторам.\
Описание: Удаление группы.
