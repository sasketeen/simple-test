# Занятие
___

| Поле       | Описание               | Пример значения      | Валидация                                                        |
|------------|------------------------|----------------------|------------------------------------------------------------------|
| discipline | Дисциплина             | "Математика"         | Минимум 1 символ                                                 |
| type       | Тип занятия            | "practice"           | Одно из значений: "practice", "laboratory", "lecture", "seminar" |
| start_date | Дата начала            | 2025-09-01T10:00:00Z |                                                                  |
| duration   | Длительность (мин)     | 90                   | Число больше 0                                                   |
| groups     | ID учебных групп       | ["1", "12"]          | Минимум 1 группа                                                 |
| classrooms | ID аудиторий занятий   | ["1", "12"]          |                                                                  |

[//]: # (| teachers   | ID преподавателей    | ["1", "12"]          |                                                                  |)


## Методы

**CREATE**\
Доступность: только администраторам\
Описание: Создание нового занятия. Поля `discipline`, `type`, `start_date`, `end_date`, `groups` обязательны

**UPDATE**\
Доступность: только администраторам
Описание: Обновление данных занятия.

**READ**
Доступность: всем\
Описание: Просмотр информации о занятии.

**DELETE**\
Доступность: только администраторам.\
Описание: Удаление занятия.

**SEARCH**\
Доступность: всем\
Описание: Поиск занятий. Возможность искать и фильтровать занятия по группе и датам
