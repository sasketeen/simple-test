# Аудитория
___

| Поле        | Описание        | Пример значения | Валидация                                                 |
|-------------|-----------------|-----------------|-----------------------------------------------------------|
| number      | Номер аудитории | "1234"          | Минимум 1 символ                                          |
| capacity    | Вместимость     | 65              | Больше 0                                                  |
| type        | Тип аудитории   | "general"       | Одно из значений: "general", "lab", "lecture_hall", "gym" |

## Методы

**CREATE**\
Доступность: только администраторам\
Описание: Создание новой аудитории. Поля `number`, `capacity` и `type` обязательны

**UPDATE**\
Доступность: только администраторам
Описание: Обновление данных аудитории. Возможность изменения номера, вместимости или типа аудитории

**READ**
Доступность: всем\
Описание: Просмотр информации об аудитории

**DELETE**\
Доступность: только администраторам.\
Описание: Удаление аудитории. Удалить аудиторию можно только в том случае, если она не привязана к занятиям.
